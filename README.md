# VC-weather-api

An API Study Project  
Link to description: https://roadmap.sh/projects/weather-api-wrapper-service

The project using:
+ Nodejs, ExpressJS
+ Redis for Cache

Requirement:
+ Installed Nodejs, npm

Usage:
+ Clone repository
+ Install required packages:
  ```
  npm install express redis axios express-rate-limit dotenv
  ```
+ Run with command:
  ```
  node server
  ```
+ Using api by url:
  ```
  localhost:3000/weather/:country
  ```
  + :country : Valid country name
